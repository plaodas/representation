# 表象 / representation

パブリックドメインの自由詩、俳句、短歌、定型詩を静かに味わうアプリです。自由詩と定型詩は日本語と英語が交互に現れ、俳句と短歌は日本語で届きます。今日の一首に「好き」「嫌い」やひとことを残しながら、次の一首を読み進められます。

製品の仕様は [PLAN.md](PLAN.md)、見た目や動きの指針は [design.md](design.md)、実装の範囲は [AGENTS.md](AGENTS.md) にまとめています。

## 動作環境

- Node.js 22.13 以降、または 24.3 以降
- npm

## 起動の手順

依存関係を準備して、Web ブラウザで開きます。

```bash
npm install
npm run web
```

ブラウザで `http://localhost:8081` が開きます。「今日」「好み」「読んだ詩」の 3 つの画面をお使いいただけます。

### スマートフォンで確認する

手元のスマートフォンで画面を確かめるときは、Expo Go を通して接続します。

1. スマートフォンに Expo Go アプリをインストールします（SDK 57 対応版）。
2. PC とスマートフォンを同じ Wi-Fi ネットワークに接続します。
3. すでに起動中の開発サーバーがある場合は終了しておきます。
4. 以下のコマンドで起動します。

```bash
npm start
```

5. ターミナルに表示される QR コードを読み取ります。
   - Android: Expo Go アプリ内の「Scan QR code」から読み取ります。
   - iPhone: 標準のカメラアプリで QR コードを読み取り、Expo Go で開きます。

WSL2 環境などで接続が届きにくい場合は、トンネル接続を利用できます（初回のみトンネル用パッケージの取得にネットワーク接続を使います）。

```bash
npx expo start --tunnel
```

読み進めた位置や残した反応は、操作したそれぞれの端末内に保存されます。詩の本文はすべて `data/poems.json` に同梱してあるため、手元のデータからそのまま読めます。

## テストの実行

次の一首を選ぶロジックや読み進めの進行をテストします。

```bash
npm test
```

## 詩の同梱スクリプト

収録している詩は、青空文庫や Project Gutenberg の公開ファイルから切り出しています。同梱データを新しく生成する際にはネットワーク接続を使用します。

```bash
node scripts/extract-poems.mjs
```
